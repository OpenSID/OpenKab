# Pull Request: Smoke Test Pengaturan OpenSID & Pengaturan Peta

## Deskripsi

Menambahkan smoke test Pest v4 + Playwright untuk halaman Pengaturan OpenSID (Program Bantuan, Kategori Artikel, Artikel) dan Pengaturan Peta (Lokasi, Tipe Lokasi). Test menggunakan MSW mocking untuk mengintersep API call eksternal agar test bisa berjalan tanpa dependensi database gabungan.

### Perubahan yang dilakukan:

1. **[Test File]**: Membuat `SmokeProgramBantuanTest.php` — 6 test untuk halaman `/master/bantuan` (page, tambah, datatable, rows, edit+delete, no errors)
2. **[Test File]**: Membuat `SmokeProgramBantuan2Test.php` — 7 test untuk halaman `/bantuan` (page, filter, datatable, rows, rincian, no errors)
3. **[Test File]**: Membuat `SmokeKategoriArtikelTest.php` — 6 test untuk halaman `/master/kategori/0` (page, tambah, datatable, rows, edit+delete+rincian, no errors)
4. **[Test File]**: Membuat `SmokeArtikelTest.php` — 6 test untuk halaman `/master/artikel` (page, tambah, datatable, rows, edit+delete, no errors)
5. **[Test File]**: Membuat `SmokeLokasiTest.php` — 4 test untuk halaman `/plan` (page, filter, datatable, no errors)
6. **[Test File]**: Membuat `SmokeTipeLokasiTest.php` — 9 test untuk halaman `/point` (page, filter, tambah, hapus-multi, datatable, rows, checkbox, edit+delete+rincian+lock, no errors)
7. **[Fixture]**: Membuat 7 file fixture JSON untuk mock API response: `bantuan-kabupaten.json`, `kategori-artikel.json`, `kategori-tampil.json`, `artikel-list.json`, `plan-lokasi.json`, `point-tipe-lokasi.json`, `point-status.json`
8. **[MSW Route]**: Menambahkan 7 route baru di `MswSetup.php` untuk mengintersep API endpoint: `/api/v1/bantuan-kabupaten`, `/api/v1/kategori`, `/api/v1/kategori/tampil`, `/api/v1/artikel/list`, `/api/v1/plan`, `/api/v1/point`, `/api/v1/point/status`
9. **[Data-testid]**: Menambahkan `data-testid` attribute ke 10 Blade template untuk selector test: `master/bantuan/index`, `master/kategori/index`, `master/artikel/index`, `bantuan/index`, `peta/lokasi/table`, `peta/lokasi/filter`, `peta/point/index`, `peta/point/table`, `peta/point/filter`
10. **[Test Group]**: Menambahkan group `pengaturan-opensid` dan `pengaturan-peta` di Pest.php untuk kemudahan menjalankan test per kategori

### Alasan perubahan:

- **Poin 1**: Issue #1069 meminta smoke test untuk memastikan fungsionalitas inti halaman Pengaturan OpenSID dan Pengaturan Peta berjalan dengan baik
- **Poin 2**: Halaman-halaman ini menggunakan API database gabungan eksternal, sehingga perlu MSW mocking agar test bisa berjalan secara independen di CI/CD
- **Poin 3**: Belum ada test sebelumnya untuk 6 halaman ini, sehingga perlu ditambahkan guna meningkatkan coverage testing

## Teknis Detail

### Arsitektur Test

```
Pest PHP (tests/Browser/*.php)
    → pest-plugin-browser
    → Playwright Server (WebSocket)
    → Chromium Browser + MSW Service Worker
    → Laravel HTTP Server (amphp)
    → Aplikasi Laravel
```

MSW (Mock Service Worker) mengintersep `fetch`/`XMLHttpRequest` di browser. Request yang cocok dengan route di `MswSetup.php` akan di-mock dengan data dari fixture JSON. Request yang tidak cocok diteruskan ke server asli.
